# Projet React

Base de travail React moderne avec Vite, TypeScript, Tailwind CSS, ESLint, Prettier,
Vitest et Playwright.

## Scripts

- `npm run dev` : lance le serveur de développement Vite.
- `npm run build` : vérifie TypeScript puis construit l'application.
- `npm run preview` : sert localement le build de production.
- `npm run lint` : analyse le code avec ESLint.
- `npm run format` : formate le projet avec Prettier.
- `npm run test` : lance les tests unitaires avec Vitest.
- `npm run test:e2e` : lance les tests end-to-end avec Playwright.

## Architecture

```txt
src/

```

## Démarrage

```bash
npm install
npm run dev
```
