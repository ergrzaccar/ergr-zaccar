# Sources internes ERGR Zaccar

Ce dossier sert uniquement a conserver les documents sources internes pendant la
preparation du site.

Regles :

- Ne pas placer ces fichiers dans `public/`.
- Ne pas creer de lien public vers les PowerPoint.
- Extraire les textes, chiffres, tableaux et informations utiles vers `src/data/`.
- Renommer les medias publics avant integration dans `public/images/`.
- Conserver ici les notes d'extraction et decisions editoriales.

Les fichiers PowerPoint places dans `presentations/` et `organigrammes/` sont ignores
par Git afin d'eviter un partage accidentel.
